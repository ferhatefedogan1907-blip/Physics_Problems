# Section 0: Mathematical Foundations — Solutions

## 1. Vector Algebra

Given:
**a = [2, 1, -3]**, **b = [4, -2, 1]**

**a) Magnitudes**
|a| = √(2² + 1² + (-3)²) = √14  
|b| = √(4² + (-2)² + 1²) = √21  

**b) Dot Product**
a · b = (2)(4) + (1)(-2) + (-3)(1) = 3  

**c) Cross Product**
a × b = [-5, -14, -8]

**d) Angle Between Vectors**
cosθ = (a·b)/(|a||b|) = 3/(√14·√21) = 3/√294  
θ ≈ 80°
